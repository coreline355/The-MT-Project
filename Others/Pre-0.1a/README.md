# Pre-0.1 Alpha Versions.

**For the celebration of MuffinText's 1st aniversary / 1 year since MT 0.1 Alpha release** (28/10/2026), i'm publishing in this directory as a historic archive, four builds packaged before the launch of MT 0.1. All these builds are prototypes and i'm not providing updates to these builds. This software is unmodified past its packaging. However, i will not provide the packaged versions, as you can create them by your own. Just make sure to set the framerate to 60 and mark "Dynamically resize size to match window size (experimental)" on the Stage section, and you are good to go.

## About each archived version:

- Editor P-24092025: The earliest build out there. When i never tought MT would become this big. Back then, MT was just a basic Turbowarp project experimenting with a adaptative Ui, that resizes itself with the browser window.

- Editor P-17102025: This build offers a new tab ui that MT uses to this day, a prototype stage, file submenu, "insert menu", a toogle to Mouse V-Sync, and two more buttons in settings. MT 0.1 dosent changes this much from this. Aside from the lack of a command executor, script editor and console.

- Editor P-23102025: Offers a primitive script editor with basic scrool. However, the script executor is still missing. The console tab exists, but contains nothing. A run/stop buttons exists, but does nothing.

- MuffinTextEditor (MT 0.1 P1 P-27102025): The project finnally recieves the name of *MuffinText*. Before that, MT was just called "Editor". This build marks the initial devlopment of the command executor. But its still missing a console.

- MuffinTextEditor0.1a (MT 0.1 P-28102025): Its not there. Its in the releases page. This version finnally recieves a console and a primitive command executor. Aside from English support, replacing the "Press x to close" with a proper close button, and some minor tweaks.

From this, every sucessor is hosted on the Releases page.
