# Documentação do MT 0.4.x Beta

**Esse documento vale tanto para o MT 0.4, 0.4.1 e 0.4.2.**

---

## Scripts (Quase nenhuma diferença da 0.3.x)

- Apenas dois Scripts, **o Start.mts e Main.mts.**
- O Start.mts serve para configurar regras e threads para o resto do projeto.
- O Main.mts é o script que deverá contero código principal do projeto.
- **Distinção real** entre variáveis locais (apenas para um script) e globais (valem para todos os scripts)

## Expressões!

A partir do MT 0.4, as expressões estão disponíveis. Expressões no MT são inputs variáveis que você pode colocar em qualquer entrada de input de comando.

Elas são especificadas usando **parênteses**.

### Expressões disponíveis na 0.4.x:

- **(last.kp)** Retorna a última tecla pressionada.

- **(script.name)** Retorna o Script em que está sendo executada

- **(input)** Ativa uma entrada de texto a partir do console. (Espaços não são permitidos, use hashes "_" em vez disso.)

- **(sound.count)** Consulta quantos arquivos de sons existem no projeto.

- **(random.x.y)** Retorna un número inteiro aleatório. Onde "x" é o primeiro intervalo e "y" é o segundo intervalo.

**Variáveis globais e locais também podem ser inseridas como expressões:**

> (nome_da_variavel)

## Estrutura de projeto

### Multi-Threading

- Multi-Thread cooperativo não foi muito modificado nessa versão.
- São gerenciadas pelos comandos sethread e delthread.
- Podem ser auto-deletadas quando um comando **selfbomb** é rodado.
- Por enquanto sem suporte a estados de thread.

### Variáveis

- Tipos suportados: número, string, boolean
- Comando: vari (set, change) (global, local) (nome) (valor)
- Sobrescrita permitida
- Podem ser especificadas como expressões

### Comandos disponíveis

- vari (set, change) (global, local) (nome) (valor)

- Print (input) (sem aspas, sem espaço no texto)

- Repeat

- Setflag (input) (vezes em que pode ser chamada)
  quando uma flag é chamada, o executor vai até a flag e continua a partir dela, se a flag estiver inválida, nada será feito.

- Gotoflag (input)

- setrule (regra) (valor)

- sethread (thread) (script para rodar)

- delthread (thread)

- if / endif

- selfbomb

- playaudio (nome do arquivo de som)

- wait.s (segundos) **(Espera uma quantidade determinada de segundos, números decimais são aceitos.)**

- wait.kp (tecla) **(Espera uam tecla especificada ser pressionada antes de continuar.)**

### Comentários

Para fazer um comentário, basta:

- "# (conteúdo) #"

## If e comparação

**Estruturas condicionais básicas finalmente foram implementadas depois da reescrita Shedexec.**

### Como usar:

**O if do MT consiste em três argumentos:**

> if (1) (2) (3)

- O Argumento 1 e 3 podem ser tanto uma expressão/variável quanto um valor literal.

- O Argumento 2 é o comparador, que pode ser:

> **== (igual)**
> 
> **>> (maior que)**
> 
> **<< (menor que)**
> 
> **>= (maior ou igual que)**
> 
> **<= (menor ou igual que)**

Depois que você inserir os comandos dentro do if, você o encerra usando **endif**.

### Observe um exemplo do uso de uma estrutura condicional:

if (idade) << 13

> print você
> 
> print é
> 
> print menor
> 
> print de
> 
> print idade!

endif

A estrutura condicional acima verifica se a variável *idade* é menor do que o valor literal especificado, que nesse caso é *13*, se a variável for menor que o valor especificado, o MT rodará o comando dentro do if. Caso contrário ele irá pular até o **endif**.

## Salvamento de projeto e arquivos de sons

A partir do MT 0.4, você finalmente pode **salvar e abrir projetos**.

O MT usa um **formato de projeto próprio .mtpf (Muffin Text Project File)**.

### Arquivo de sons

O MT por enquanto suporta sons .mp3 e .ogg. Mas eles **Não são salvos no projeto.**

Você pode fazer upload desses arquivos de audio, dar um nome para eles, e tocar eles via comando **playaudio**.

## Regras de Execução

- **Loudscript:** se definido para 1, retorna mais informações sobre a execução, útil para debug.
- **MaxThreads:** se definida para qualquer valor, não deixa existir mais threads do que aquele valor, por exemplo, se MaxThreads estiver definido para *16*, não existirão mais que *16* threads. Solicitações de criação de threads se o limite estivr atingido serão recusadas internamente.
- **SpeedCap:** Defina essa regra para *0* e o MT irá rodar sem limite! Ou seja, ele vai rodar absurdamente rápido, se você não quer isso, defina qualquer número no Speedcap para limitar a velocidade de execução do MT. **(NÃO COLOQUE VALORES NEGATIVOS!)**
- **ConsoleSize:** Se definido para *auto*, o tamanho do console irá mudar conforme o tamanho da janela, se não quiser isso, pode colocar qualquer número para mudar o tamanho do console para um tamanho fixo.

## Limitações Conhecidas

- Sem suporte a mais de dois scripts.
- Sem suporte a estruturas [nested if](https://www.google.com/search?q=nested+if).
- Arquivos de sons não são salvos.
