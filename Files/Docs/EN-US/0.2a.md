# Muffin Text 0.2 Alpha

## Scripts
- Only one script
- No real distinction between local/global (globals only)

## Variables
- Supported types: number, string
- Command: Variablet(set, change) (global, local) (name) (value)
- Overwriting allowed

## Available commands
- Variablet (set, change) (global, local) (name) (value)
- Print (thing) (without quotes, without spaces in the text)
- Repeat
- ###If (variable)( =, <, >) (value)

(commands between ###if and ###endif)

###endif

- Setflag(name) (number of times it can be called)
When a flag is called, the executor goes to the flag and continues from there; if the flag is invalid, nothing will be done.

- Gotoflag (flag name)
- setrule (rule) (value)

## Executor Rules
- **Loudscript:** if set to true, returns more information about the execution, useful for debugging.

- That's all lol

## If and Comparison
- Direct comparison
- Several limitations

## Executor
- Parser + executor model
- Sequential execution
- Fixed Low FPS

## Known Limitations
- FPS capped at 32
- No support for multiple scripts
- No support for comments
- No support for saving projects
